# 🔁 DEDUPLICATION LOGIC

Listings are duplicates if:

* Same street (fuzzy match)
* Rent within ± €50
* Size within ± 5 m²

Example:

```python
from rapidfuzz import fuzz

if fuzz.ratio(a.street, b.street) > 85:
    # possible duplicate
```

# 🧠 ENGINEERING TIPS (VERY IMPORTANT)

### 1. Don’t scrape everything with Playwright

Use:

* Requests first
* Playwright only when necessary

---

### 2. Cache everything

Avoid re-processing same listings

---

### 3. Be polite to websites

* Add delays
* Don’t hammer endpoints

---

### 4. Human-in-the-loop > full automation

Never auto-send messages at first

---

### 5. Build in layers

1. Scraper
2. Alerts
3. Deduplication
4. Dashboard
